# Публикация на GitHub

Исходники проекта не требуют установки зависимостей или сборки интерфейса.
Для GitHub нужны код, HTML-шаблон, тесты, документация, список CIDR и уведомление
IPdeny. Рабочие результаты и скриншоты исключены через `.gitignore`.

## Отправка локального репозитория

Создайте пустой репозиторий в своём аккаунте GitHub. Если используете уже
подготовленную локальную папку с веткой `main`, выполните из неё:

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Замените `USERNAME/REPOSITORY` на свой адрес репозитория. Аутентификация
выполняется вашим обычным способом GitHub. Проверить настроенные адреса можно
через `git remote -v`.

Если начинаете с архива исходников без каталога `.git`:

```bash
git init -b main
git add .
git commit -m "Initial import"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

## Через веб-интерфейс

Распакуйте архив и загрузите его содержимое в корень нового репозитория.
`README.md`, `report_template.html`, папка `tests` и папка `.github` должны
находиться на своих местах. Загрузка ZIP как одного файла не заменяет
публикацию исходников.

После отправки GitHub Actions запустит тесты. Настроены Ubuntu, Windows и macOS
с Python 3.10 и 3.13; сетевые ответы в тестах подменяются.

Происхождение кода и статус лицензирования указаны в [`NOTICE.md`](../NOTICE.md).
Файлы `cidrs.txt` и `Copyrights.txt` нужно сохранять вместе с метаданными
источника. `.gitattributes` сохраняет их байты, чтобы SHA-256 не зависел от ОС.
