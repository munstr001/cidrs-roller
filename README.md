# CIDR Scanner

Проверка отдельных IPv4-адресов из списка подсетей через **ICMP (ping)** или **TCP**. Программа сохраняет историю попыток, позволяет продолжить прерванное сканирование и создаёт автономный HTML-отчёт с поиском и фильтрами.

Работает на Windows, Linux и macOS. Использует стандартную библиотеку Python — установка пакетов через `pip` не нужна.

## Возможности

- Детерминированная выборка адресов: первый, средний и последний либо заданное количество образцов.
- Параллельные проверки, ограничение частоты запросов, тайм-ауты и повторные попытки.
- Прогресс, фактическая скорость и примерное оставшееся время.
- Продолжение через `--resume` с сохранением готовых результатов.
- JSONL с конкретными IP и историей каждой попытки.
- `reachable-cidrs.txt`: исходные CIDR, в которых хотя бы один IP когда-либо ответил.
- HTML-отчёт: поиск IP/CIDR, фильтры, сортировка, страницы, темы и подробности попыток.
- Дополнительный фильтр частичных ответов по первому, среднему и последнему образцу, включая точные сочетания.

Ответ одного образца подтверждает доступность этого IP выбранным способом. Он не подтверждает весь диапазон или включение адреса в мобильный белый список.

## Требования

- **Python 3.10+**.
- Для ICMP — системная команда `ping`, доступная через `PATH`.
- Для TCP дополнительные программы не нужны.

## Быстрый запуск

Скачайте исходники или клонируйте репозиторий. Из папки проекта:

```bash
python3 real-check-avaibility.py --help
python3 real-check-avaibility.py --input cidrs.txt --source-label "my-network"
```

На Windows используйте `python`, если команда `python3` недоступна.

Входной файл содержит IPv4 или CIDR, по одному на строку. Комментарии начинаются с `#`. Например:

```text
203.0.113.0/24
198.51.100.42
```

Это адреса для примера формата. Поставляемый `cidrs.txt` содержит **11 482 подсети RU** из снимка IPdeny от **4 ноября 2026 года**. При стандартных трёх образцах это 34 446 проверок отдельных IP, а не перебор всех адресов диапазонов.

Проверка TCP-порта 443:

```bash
python3 real-check-avaibility.py --protocol tcp --port 443 --timeout 2 --workers 16 --rate 20
```

## Основные параметры

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `--input FILE` | `cidrs.txt` рядом со скриптом | IPv4/CIDR для проверки |
| `--protocol icmp\|tcp` | `icmp` | Способ проверки |
| `--port N` | `443` | Порт TCP |
| `--samples N` | `3` | До N разных IP из каждой подсети, 1–256 |
| `--attempts N` | `2` | До N попыток для каждого IP, 1–10 |
| `--timeout SECONDS` | `1` | Тайм-аут одной попытки, не более 60 секунд |
| `--workers N` | `16` | Параллельные проверки, 1–256 |
| `--rate N` | `20` | Максимум начала сетевых попыток в секунду, включая повторы |
| `--source-label TEXT` | `unspecified` | Подпись подключения |
| `--output-dir DIR` | Новая папка в `results/` | Новый каталог результатов |
| `--resume DIR` | — | Продолжить существующий запуск |

`--samples 2` проверяет первый и последний хостовые адреса. Повторные попытки задаются отдельно через `--attempts`. Если хостовых адресов меньше выбранного количества, проверяются только имеющиеся.

Полное описание параметров, выборки, статусов и восстановления: **[руководство пользователя](docs/USAGE.md)**.

## Результаты

Каждый запуск создаёт отдельный каталог:

```text
results/scan-.../
├── manifest.json
├── results.jsonl
├── errors.jsonl
├── reachable-cidrs.txt
├── report.html
└── grouped/
    ├── reachable-ips.jsonl
    ├── errors-ips.jsonl
    ├── unreachable-ips.jsonl
    ├── networks.jsonl
    ├── all-replied-networks.jsonl
    ├── partial-networks.jsonl
    ├── incomplete-networks.jsonl
    └── summary.jsonl
```

- **JSONL** сохраняет конкретные IP, исходные CIDR, статус, причины и попытки.
- **TXT** содержит уникальные исходные CIDR с хотя бы одним подтверждённым ответом за историю запуска. Маски сохраняются, соседние сети не объединяются.
- **HTML** открывается обычным браузером без сервера и интернета. В нём есть фильтры по результатам и ответившим образцам, страницы и подробности.

Результаты отдельных IP сохраняются сразу. Группировка и HTML формируются после завершения или остановки через `Ctrl+C`; после продолжения они обновляются. Незавершённые проверки отделены от отсутствия ответа. Старый `reachable-ips.txt` автоматически заменяется на `reachable-cidrs.txt` по сохранённым подтверждениям.

## Продолжение и пересборка отчёта

Продолжить существующий запуск:

```bash
python3 real-check-avaibility.py --resume results/scan-EXAMPLE --workers 32 --rate 50
```

Замените `scan-EXAMPLE` на имя своей папки. Можно менять `workers` и `rate`; входной список и параметры измерений должны совпадать с манифестом. `--resume` и `--output-dir` не используются вместе.

Если исходный файл перемещён, укажите его через `--input`. Содержимое должно совпадать по SHA-256.

Пересобрать HTML, TXT и группировку из готового журнала без новых сетевых проверок:

```bash
python3 export_results.py results/scan-EXAMPLE --input cidrs.txt
```

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют временные каталоги и подменённые сетевые ответы. Реальное массовое сканирование не выполняется. GitHub Actions настроен на Python 3.10 и 3.13 под Ubuntu, Windows и macOS.

## Происхождение и условия использования

Проект основан на переработке [munstr001/cidrs-roller](https://github.com/munstr001/cidrs-roller). Происхождение и статус лицензирования исходного кода описаны в [NOTICE.md](NOTICE.md).

Данные IPdeny сопровождаются неизменённым [Copyrights.txt](Copyrights.txt) и метаданными [cidrs.source.json](cidrs.source.json). Классификация RU относится к стране регистрации или распределения ресурсов, а не гарантирует физическое расположение адреса. Результат проверки относится к фактическому подключению устройства; `--source-label` лишь задаёт подпись и не определяет оператора автоматически.
