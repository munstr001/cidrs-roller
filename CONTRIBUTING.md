# Разработка

Для работы нужны Python 3.10+ и Git. Сторонних Python-зависимостей нет.
Для ручной ICMP-проверки нужна системная команда `ping`; тесты подменяют
сетевые ответы и не выполняют реальное сканирование.

Проверка перед отправкой изменений:

```bash
python3 -m unittest discover -s tests -v
python3 real-check-avaibility.py --help
python3 export_results.py --help
```

На Windows можно использовать `python` вместо `python3`.
GitHub Actions выполняет эти проверки на Ubuntu, Windows и macOS для
Python 3.10 и 3.13.

## Устройство

- `cidr_scanner.py` — параметры, выборка, параллельные проверки и продолжение.
- `cidr_probes.py` — отдельная попытка ICMP или TCP.
- `cidr_journal.py` — история результатов, блокировка записи и TXT с CIDR.
- `cidr_exports.py` — группировка последних результатов и публикация отчётов.
- `cidr_html.py`, `report_template.html` — автономный HTML с фильтрами.
- `scan_progress.py` — прогресс и приблизительное оставшееся время.

Изменения выборки, повторов, восстановления и экспорта следует проверять
на небольших синтетических наборах адресов из тестовых диапазонов. Для
изменений HTML отдельно проверьте фильтры, страницы и мобильную ширину.

Результаты сканирования и скриншоты реальных измерений не входят в исходники.
Файл `cidrs.txt` сверяется по байтовому SHA-256: при обновлении списка
обновляйте `cidrs.source.json` и сохраняйте исходное уведомление IPdeny.
Происхождение и статус лицензирования описаны в [`NOTICE.md`](NOTICE.md).
